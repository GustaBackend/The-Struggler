# Entrega 0.2.0 — Guarda vanilla e GeckoLib

Esta entrega preserva os artefatos já compilados e testados, sem recompilar ou modificar funcionalidades. O código correspondente e a cópia de fontes dentro do pacote completo vêm do commit `12a699d2679a91e05fe6c8cc7b83fa09f352bc0c`, na branch `feature/midland-guard-visual`. O commit desta atualização acrescenta a documentação e os hashes da publicação. A branch principal e a fundação 0.1.0 permanecem intactas.

## Download no GitHub

[Release v0.2.0-vanilla-geckolib](https://github.com/GustaBackend/The-Struggler/releases/tag/v0.2.0-vanilla-geckolib)

A Release está marcada como pré-lançamento: ataque/defesa ainda são demonstrações visuais, não combate autônomo ou bloqueio de dano.

Arquivos da Release:

- `struggler-0.2.0.jar`: mod compilado e testado.
- `geckolib-forge-1.20.1-4.7.2.jar`: dependência externa necessária, distribuição original sem alterações.
- `struggler-0.2.0-vanilla-geckolib-completo.zip`: os dois JARs, projeto, modelo editável, textura, animações, capturas, vídeos, logs de build/runtime e relatório; 86 arquivos.
- `midland_guard.bbmodel`: modelo editável do Blockbench.
- `relatorio-vanilla-geckolib.md`: resultados e limitações do teste real.
- `final-idle-attack-defend.mp4`, `final-walk-run.mp4`, `final-hurt-death.mp4`: gravações do cliente Minecraft.
- `SHA256SUMS-release.txt`: hashes dos oito arquivos anteriores.

O ZIP inclui todos os logs e capturas entregues da versão final. Vídeos também estão disponíveis como arquivos separados da Release. Os binários ficam nos anexos da Release, não no histórico Git, para evitar aumentar o tamanho do clone. A documentação e os hashes estão versionados nesta branch.

## Instalação

Use Minecraft Java **1.20.1**, Forge **47.4.28** e Java **17**. Coloque Struggler 0.2.0 e GeckoLib 4.7.2 na pasta `mods`. Remova outras versões do Struggler dessa mesma instância. GeckoLib não está embutido no JAR do Struggler.

## Validação e procedência

A execução real validou carregamento no cliente Forge, entrada em mundo isolado, invocação pelo ovo, aparência, saudação, deslocamento e clips; dano/morte usaram eventos reais do Minecraft. Consulte o relatório para ressalvas de áudio/perfil offline e testes não realizados. BUILD SUCCESSFUL é apenas o resultado de compilação, não substitui esse teste.

Para conferir a integridade dos downloads em Linux, execute `sha256sum -c SHA256SUMS-release.txt` no diretório com os arquivos baixados. O JAR do Struggler preserva SHA-256 `453186cb86c3c9461ed48b94d3f34c712b2b5ee6a1a79376d20f67144e9db334`.

GeckoLib 4.7.2 para Forge 1.20.1 foi obtido da [distribuição oficial Modrinth](https://modrinth.com/mod/geckolib/version/AiVKLYep). O pacote completo contém a cópia de fontes do commit original dos artefatos; a atualização de entrega é apenas documental.
