# The Struggler — Forge mod prototype

**Target:** Minecraft Java 1.20.1 / Forge 47.4.28 / Java 17  
**Status:** source scaffold — not yet compiled or game-tested.

This is the first custom-mod foundation for the BERSERK-inspired modpack. It currently registers:
- A prototype Midland Guard entity with basic wandering/look behavior.
- A spawn egg for testing the entity in a development world.
- A custom item named Behelit (currently decorative; no supernatural event logic yet).

## Important
This ZIP contains source code and Gradle project files. It is **not** a ready-to-drop `.jar` and is not yet a finished modpack. It must be compiled and tested in a Forge 1.20.1 / 47.4.28 development environment.

## Build
1. Install a 64-bit JDK 17.
2. Install Gradle 8.x or use the Gradle wrapper generated by the official Forge MDK.
3. Import this folder into IntelliJ IDEA as a Gradle project.
4. Run `genIntellijRuns` if needed, then run the `runClient` Gradle task.
5. In a creative test world, use the spawn egg named `Midland Guard Spawn Egg`.
6. Check `logs/latest.log` for registration or rendering errors.
